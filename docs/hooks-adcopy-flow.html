3 Ad Copy · Auto-filled
Wizard structures the hooks into a numbered list
Top picks lead the numbering as PRIORITY. The rest follow as FULL HOOK LIST with their angle category tagged. The cleaned list lands in the Ad Copy form's hooks_markdown field before you click Generate.

4 Ad Copy · Output
Vortex writes 12 ads, each tagged with its hook
Every priority hook opens at least one ad. ≥ 8 of 12 openers are lifted from the numbered list (light adaptation allowed). Each ad's label shows the framework, the hook reference, and the word count — so you can trace any winning ad back to the hook that opened it.

What this gets you. Every ad in the output names the hook that opened it (e.g. HOOK #3 · social_proof). When ads run live, the winners can be traced straight back to the hooks that drove them — which informs the next Hooks run. If you skip the Hooks step or run Ad Copy outside the wizard, the label simply reads FRESH HOOK · <category> and Vortex writes its own openers in the same voice. The chain is opportunistic, never blocking.
