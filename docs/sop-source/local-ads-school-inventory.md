## How this doc works

This is the staging map for turning Local Ads School lessons into Command Center SOPs.

1. **Now (done):** every lesson in the two target courses is listed below with its runtime, watched-status, and both a direct Loom/YouTube `video` link and the `skool` lesson link.
2. **Next (Jake triages):** mark the **Action** column for each lesson:
   - `SOP` = turn this into a full step-by-step SOP
   - `KEEP` = keep as reference, no SOP needed
   - `CUT` = drop it, not relevant
3. **Then (on "go"):** the marked rows get pushed into the Command Center SOP hub.
4. **Finally:** for every `SOP` row, run the `/watch` skill on the `video` link to build the real step-by-step process.

**Action legend:** `SOP` / `KEEP` / `CUT` (leave blank = undecided)
