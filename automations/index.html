Setup: map the calendars

Done once per client in your admin. This is what turns every workflow below on.

⚙️
Admin action
Open a client's admin page
Command Center → Clients → [client] → Calendars
📅
Select
Estimate calendar
Pick from the sub-account's live GoHighLevel calendars.
GoHighLevel
📅
Select
Job calendar
Pick from the sub-account's live GoHighLevel calendars.
GoHighLevel
✓
Result
Jobs tab turns on for this client
It now reads those two calendars. Nothing mapped = the client sees a "not connected yet" state.
End

⚡
Trigger

In the client's Estimate calendar.
GoHighLevel
