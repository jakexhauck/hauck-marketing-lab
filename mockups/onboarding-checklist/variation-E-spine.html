04Creative Production

Twelve steps, in this exact order, every client. Strategy doc first — hooks before copy — copy before visuals. By the end: nine ads (three statics, three carousels, three videos), every one traceable back to the strategy doc.

Day 4 – 7
4 / 12 Steps complete
Parallel track Runs alongside Phase 3 — Account & Tracking Setup. Don't wait for pixel verification; build creative now.
Step 01 Strategy doc first1 hour ▸

Before code, before Canva. Locks in assets/strategy.md. Everything downstream is built off this doc — if it's wrong, the ads are wrong.

  • Offer — the one thing we're selling
    • One sentence. No menu. Example: $99 first window cleaning.
    • If you can't say it without "and" or "plus," it's two offers — pick one.
    • Match this to whatever the landing page (or call script) actually delivers.
  • Audience — who specifically
    • Demographic + geo radius. Example: homeowners 35–65, 20mi around Phoenix.
    • Pull this from the discovery form (Phase 1) — don't guess.
    • This becomes the ad-set audience name in Phase 5 verbatim.
  • Pain point — what's bugging them
    • Use the client's words from the kickoff transcript, not marketing-speak.
    • Willis example: dirty windows, no time, embarrassed when guests come over.
    • Three is plenty. More is noise.
  • Desire — what they actually want
    • The end-state, not the product. Clean home, peace of mind, one less chore.
    • Desire fuels hooks. Pain fuels copy. Keep them in separate columns.
  • Objections — top 3 reasons they'd say no
    • Price, trust, "I'll do it myself" — the usual suspects for home services.
    • Each objection needs a counter in the proof list below. One-to-one.
  • Proof — what we have to back it up
    • Testimonials (with names + city), before/afters, review counts, years in business.
    • If proof is thin, schedule a 30-min shoot now (Step 08 will need it anyway).
Step 02 Angles30 min ▸

Five distinct angles — not twelve. Pick the top three to actually build; park the other two for refresh week.

  • Open the Creative Brief Builder in the app
    • Loads strategy.md automatically. If it asks for inputs, Step 01 isn't done.
    • Output drops into creatives/angles.md.
  • Generate 5 distinct angles for Willis Windows
    • Distinct = different emotion driving the click. Not five flavors of "we clean good."
    • Working set: Embarrassment / Time-saving / Curb appeal / Spring seasonal / Social proof.
    • If two angles can use the same hook, they're the same angle — merge them.
  • Pick top 3 to actually build. Park the other 2.
    • Tag each with "build" or "park" in angles.md — we revisit at week 3 refresh.
    • Bias to the angle the client's testimonials already prove. Easier copy, faster approval.
Step 03 Hooks45 min ▸

Hooks before copy. Hooks before visuals. Always. The first 1.5 seconds. If the hook doesn't stop the scroll, nothing else matters.

  • Run Hook Generator per angle — 10 each, 30 total
    • App pre-loads the angle context. One pass per angle, don't batch them.
    • Mix formats: question, statement, pattern interrupt, social proof, contrarian.
  • Cull to top 3 per angle — 9 surviving hooks
    • Read each one aloud. If you stumble, kill it. Phone-scrolling test.
    • 6th-grade reading level max. No jargon. No "synergy."
  • Save to creatives/hooks.md
    • Group by angle, numbered 1–9. Each hook gets a one-line "why this works" note.
    • This file feeds Step 04 (copy) and Step 11 (video text overlays).
Step 04 Primary text / body copy1 hour ▸

One framework per angle — don't mix. PAS for angle 1, BAB for angle 2, Story for angle 3. Output: 5–7 lines, 6th-grade level, one clear CTA.

  • Angle 1 — PAS (Problem · Agitate · Solution)
    • Lead with the pain. Twist the knife. Then the offer as relief.
    • Save to creatives/copy/embarrassment.md.
  • Angle 2 — BAB (Before · After · Bridge)
    • Paint the current Saturday (chores, ladder, frustration) → the new Saturday → how we get there.
    • Save to creatives/copy/time-saving.md.
  • Angle 3 — Story
    • Real client story, names changed if needed. Beginning, middle, payoff.
    • Save to creatives/copy/curb-appeal.md.
  • One clear CTA per ad — no "learn more, or call, or book"
    • Match the CTA button you'll set in Phase 5: Get Quote / Book Now / Learn More.
    • If the offer is "$99 first clean," the CTA is "Book your $99 clean." Direct.
