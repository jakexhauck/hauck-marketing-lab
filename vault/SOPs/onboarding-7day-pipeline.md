# Client Onboarding, 7-Day Launch Pipeline

**Category:** Onboarding
**Source:** Module 3 Lesson 1, Module 3 Lesson 7
**When to use:** Client just signed and paid. Run this every time, no exceptions.
**Estimated time:** 4 to 5 hours of your time across 7 days

---

## Prerequisites

- [ ] Contract signed (DocuSign or PandaDoc)
- [ ] First payment cleared
- [ ] Welcome email sent with onboarding form

## Checklist

- [ ] **Day 1, Onboarding Call (30 min)**
  - [ ] Walk through onboarding form together
  - [ ] Collect Meta Business Manager access (Partner level)
  - [ ] Collect website access for pixel install
  - [ ] Collect Google Analytics access (Viewer)
  - [ ] Request brand assets via shared Google Drive folder
  - [ ] Confirm primary offer and CTA
  - [ ] Set expectations: ads live within 7 days, real data after 5 to 7 days, weekly Monday updates, monthly call on the 1st
- [ ] **Day 2, Research and Setup (60 min)**
  - [ ] Set up or audit Meta ad account
  - [ ] Install Meta Pixel via GTM
  - [ ] Verify pixel firing with Meta Pixel Helper and Test Events
  - [ ] Add payment method to ad account
  - [ ] Run Nexus competitor and audience research
- [ ] **Day 3 to 4, Creative Production (60 min)**
  - [ ] Generate 12+ ad copy variations across PAS, AIDA, BAB, Story frameworks
  - [ ] Generate 15 to 25 creatives across 4+ formats (image, carousel, video, UGC, before/after)
  - [ ] Send top 3 to 5 creatives to client for written approval
- [ ] **Day 5 to 6, Campaign Build + QA (45 min)**
  - [ ] Build campaign per structure SOP, broad targeting, location radius set
  - [ ] Upload all creatives, Advantage Creative toggles OFF
  - [ ] Run pre-launch QA checklist
  - [ ] Do not publish yet
- [ ] **Day 7, Launch + Monitor (25 min)**
  - [ ] Publish campaigns, wait for Meta review (1 to 24 hours)
  - [ ] Text client: ads are live, 48-hour learning phase, real data after 3 to 5 days
  - [ ] Set up AI Campaign Optimizer with auto-pause rules
  - [ ] Schedule daily 15-min check-ins
  - [ ] Schedule first weekly report for next Monday

## Notes

- No work begins until payment clears.
- Record the onboarding call with permission.
- Naming convention for everything: [Client]_[Objective]_[Audience]_[Date].
- Same six-phase pipeline every time. Consistency is what lets one person run 10 clients.
