# Daily Workflow for 5 to 7 Clients

**Category:** Operations
**Source:** Module 4 Lesson 1
**When to use:** Every day once you're at 3+ clients. The structure that prevents burnout.
**Estimated time:** 2.5 to 3 hours total

---

## Prerequisites

- [ ] Calendar blocks set: 9-10:15am Morning Block, 1-2:30pm Afternoon Block
- [ ] Operations Hub spreadsheet with Client Dashboard tab
- [ ] Daily tracking sheet per client

## Checklist

- [ ] **Morning Block (9:00 to 10:15am):**
  - [ ] Dashboard check across ALL clients (15 min each)
  - [ ] Review spend, CPL, frequency for each
  - [ ] Identify issues without optimizing yet
  - [ ] Document action items per client
  - [ ] Do NOT execute changes during this block
- [ ] **Afternoon Block (1:00 to 2:30pm):**
  - [ ] Execute ALL optimizations across clients in one session
  - [ ] Batch creative refreshes (write all copy, then generate all images, then upload all creatives)
  - [ ] Reply to ALL accumulated client messages in one session
  - [ ] Set client response expectation: 4 to 6 hours
- [ ] **Done by 3:00pm.**
- [ ] **Apply the 1-hour-per-client max:**
  - [ ] Normal day: 15 to 30 min per client (dashboard 10 min, tweaks 10 min, reply 5 min)
  - [ ] Heavy day: 45 to 60 min per client (dashboard 10, creative batch 25, restructure 15)
  - [ ] If you exceed 2 hours per client, over-servicing or missing systems
- [ ] **Use task batching, NOT sequential per-client:**
  - [ ] Wrong: do everything for Client A, then everything for Client B...
  - [ ] Right: check ALL dashboards (75 min), write ALL ad copy (30 min), generate ALL images (20 min), upload ALL creatives (15 min), reply ALL messages (15 min)
- [ ] **Track in tools:**
  - [ ] Google Calendar: color-coded blocks by client
  - [ ] Google Sheets: client tracker (name, retainer, dates, status)
  - [ ] Google Drive: organized folders per client with subfolders (use _CLIENT TEMPLATE)
  - [ ] Slack/WhatsApp: one channel per client, batch replies 1 to 2x daily

## Notes

- Sequential context switching = 6+ hours exhausted. Batched = 2.5 hours energized. The math is the same, the cognitive load isn't.
- Weekly rhythm:
  - [ ] Monday: dashboard checks + weekly planning
  - [ ] Tuesday: optimizations + creative refreshes
  - [ ] Wednesday: dashboard checks + client calls
  - [ ] Thursday: client calls + batch weekly reports
  - [ ] Friday: light checks + prospecting
  - [ ] Sat/Sun: off (ads run autonomously)
- Going from 1 client to 5 doesn't take 5x the work. Most of what you do is the same, you just repeat it across accounts.
