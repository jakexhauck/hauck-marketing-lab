# Weekly + Monthly Client Communication Rhythm

**Category:** Comms
**Source:** Module 3 Lesson 13
**When to use:** Every active client, ongoing. Set the rhythm Day 1 and never break it.
**Estimated time:** Built-in to weekly + monthly cadence

---

## Prerequisites

- [ ] Day 1 expectations communicated to client: weekly Monday updates, monthly call on the 1st
- [ ] Client's preferred channel known (text, email, Slack, WhatsApp)
- [ ] Recurring calendar blocks set

## Checklist

- [ ] **Weekly (every Monday, same time):**
  - [ ] Send 5 to 8 sentence update via preferred channel
  - [ ] Format per weekly-client-report SOP
  - [ ] No exceptions, no skipping
- [ ] **Monthly (first week of every month):**
  - [ ] Run 30-min strategy call (10/10/10)
  - [ ] Send monthly report 1 day before
  - [ ] Schedule next month's call before hanging up
- [ ] **As needed:**
  - [ ] Share wins immediately (don't wait for Monday)
  - [ ] Report problems BEFORE clients discover them
  - [ ] Address tough conversations same day, not next week
- [ ] **Expectation setting on Day 1:**
  - [ ] Week 1 to 2 is testing
  - [ ] Week 3 to 4 the algorithm optimizes
  - [ ] Month 2+ we scale
  - [ ] Weekly Monday updates, monthly call on the 1st
  - [ ] Response time: 4 to 6 hours typical

## Notes

- The 5 rules that keep clients:
  - [ ] Communicate before they ask
  - [ ] Set expectations Day 1
  - [ ] Own bad news (address it first, never hide)
  - [ ] Always have a plan (never admit uncertainty, frame challenges with action)
  - [ ] Celebrate wins loud (share high-performing days with proof)
- $1,500 client x churn month 1 + negative review vs $1,500 x 12 = $18,000 + referrals. The difference is communication, not ad performance.
- If you're answering "where's my report?" you're already failing. Updates are proactive, always.
