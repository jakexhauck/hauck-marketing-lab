# Generate Ad Images with AI

**Category:** Creative
**Source:** Module 5 Lesson 7, Module 3 Lesson 9b
**When to use:** Every creative round. Pair with the 12 copy angles to build 12 paired ads.
**Estimated time:** 20 to 30 min for a full set

---

## Prerequisites

- [ ] Client brand kit ready (logo, brand color hex codes)
- [ ] Copy angles identified (see ad-copy-12-angle-generation)
- [ ] Image tool access: ChatGPT/DALL-E 3 (primary), Google Stitch (alternative), Midjourney or Leonardo (advanced)

## Checklist

- [ ] **For each angle, write a specific prompt using the formula:**
  - [ ] [Subject] in [setting/location], [action/pose], [style/mood], [lighting], [camera angle], [format]
  - [ ] Add: "Leave space for text overlay on [top/bottom/left/right]"
  - [ ] Never include logos or text in the AI prompt (AI butchers letterforms)
- [ ] **Specify dimensions:**
  - [ ] Square (1:1) for feed posts
  - [ ] Vertical (9:16) for stories and reels
  - [ ] Generate both per ad
- [ ] **Generate 3 to 4 variations per angle:**
  - [ ] Never use the first image
  - [ ] Pick the best variation by scroll-stopping potential (face, contrast, focal point)
- [ ] **Polish in Canva:**
  - [ ] Upload the AI image as background
  - [ ] Add the headline text on top (matches the ad copy angle)
  - [ ] Insert CTA button or text ("Book Now", "Claim Your Free Trial")
  - [ ] Drop in the client's logo (small, corner)
  - [ ] Mobile preview check (95% of users on phones)
  - [ ] Export as PNG or JPG
- [ ] **For before/after niches** (med spa, detailing, landscaping, dental):
  - [ ] Use side-by-side template: left = before state, right = after state
  - [ ] Clean white divider, BEFORE and AFTER labels at top
  - [ ] Photo realistic, square format
- [ ] **Save to client folder** under `clients/[name]/creatives/images-[date]/`

## Notes

- Prompting rules: be specific (age, clothing, lighting, mood), specify format upfront, specify style ("professional photo realistic" vs "flat illustration" vs "cinematic lighting"), plan space for text overlay, no text or logos in the AI image itself.
- Authenticity beats polish. Use "candid shot" and "natural lighting" for real feel. Stock-looking ads underperform.
- Google Stitch alternative: describe ads in plain language and iterate with voice or text. Export, then polish in Canva same as above.
- For dental, weight loss, skincare: add a "Results may vary" disclaimer in the image text. Without it, Meta's filters trigger.
