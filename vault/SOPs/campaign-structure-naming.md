# Build Campaign Structure and Naming Convention

**Category:** Build & Launch
**Source:** Module 3 Lesson 6
**When to use:** Every new campaign build. Day 5 to 6 of onboarding pipeline.
**Estimated time:** 20 to 30 min

---

## Prerequisites

- [ ] Ad account access confirmed
- [ ] Pixel installed and firing (or Lead Forms ready)
- [ ] Creatives approved by client
- [ ] Daily budget agreed with client

## Checklist

- [ ] **Decide ABO vs CBO:**
  - [ ] New client or testing new audiences: ABO
  - [ ] Proven audiences and scaling: CBO
  - [ ] Default for every new client: ABO Testing first
- [ ] **Create the campaign:**
  - [ ] Objective: Leads (for local businesses)
  - [ ] Name format: [Client] - [Goal] - [Type], e.g. "Tony's Pizza - Leads - ABO Testing"
- [ ] **Create Ad Set 1 (Broad):**
  - [ ] Name: [Audience] - [Location] - [Age], e.g. "Broad - Tampa 10mi - 25-55"
  - [ ] Budget: $10 to $15/day
  - [ ] Targeting: Broad, location radius only (no interests)
  - [ ] Age range: only if relevant to niche
- [ ] **Create Ad Set 2 (Interest test, optional):**
  - [ ] Name: "Interest - [Relevant Interest] - 25-55"
  - [ ] Budget: $10 to $15/day
  - [ ] Same 3 ads as Ad Set 1 so you test audience, not creative
- [ ] **Upload 3 ads per ad set:**
  - [ ] Name format: [Format] - [Hook/Angle] - [Version], e.g. "Image - Family Deal $19.99 - V1"
  - [ ] Mix formats: image, video, carousel
  - [ ] Mix angles: different reason to buy each
- [ ] **Verify daily total:**
  - [ ] $20 to $30/day expected at launch
  - [ ] Confirm matches what client agreed to
- [ ] **Do not publish yet.** Run pre-launch QA checklist first.

## Notes

- Three levels, top-down: Campaign (the goal), Ad Set (targeting + budget), Ad (the creative).
- Never let a client start below $10/day. Meta doesn't have enough budget to learn at that level.
- Naming saves you at 2am when a client texts "why did my ad stop?" You need to find the right campaign in 5 seconds.
- Once Ad Set 1 wins for 3+ days at target CPL, move it into a CBO campaign for scaling.
