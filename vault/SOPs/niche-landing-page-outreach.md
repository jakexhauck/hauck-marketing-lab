# Build Free Niche Landing Page for Outreach

**Category:** Leads
**Source:** Bonus, Niche Landing Page in 10 Min
**When to use:** When a prospect engages and you need to send something that looks legit, or before launching outreach to a new niche.
**Estimated time:** 10 to 15 min per page

---

## Prerequisites

- [ ] Claude.ai or Claude Code access
- [ ] GitHub account
- [ ] Vercel account connected to GitHub
- [ ] Prospect info: business name, city, niche

## Checklist

- [ ] **Pick the niche pain + dream outcome pair:**
  - [ ] Plumbing: seasonal slow / booked solid 52 weeks
  - [ ] Dentistry: empty slots, no-shows / full schedule, higher-value patients
  - [ ] Real Estate: expensive low-quality leads / motivated buyers and sellers
  - [ ] Med Spa: hard to stand out / fully booked high-ticket services
  - [ ] Gym: high churn / loyal community
  - [ ] Home Services: expensive job boards / consistent inbound year-round
  - [ ] Ecommerce: rising costs, iOS attribution / profitable ROAS
- [ ] **Run the master Claude prompt:**
  - [ ] Request a single HTML file landing page for the niche
  - [ ] Sections: hero (pain + dream outcome), What We Do, Results We Get (2 to 3 outcome bullets), How It Works (3-step: Discovery, 7-day build, Ongoing optimization), About Us (niche-focused), CTA to Calendly
  - [ ] Style: dark background (#0A0A0A), white text, blue accent (#3B82F6), mobile responsive, minimal premium, text-only, inline CSS
- [ ] **Personalize for the specific prospect:**
  - [ ] Insert prospect's business name into hero headline
  - [ ] Add line acknowledging you've reviewed their business
  - [ ] Add scarcity line: "We take one client per city"
- [ ] **Save and deploy:**
  - [ ] Save Claude output as `index.html` locally
  - [ ] Create or use GitHub repo, upload `index.html`
  - [ ] Connect repo to Vercel for automatic deployment
  - [ ] Grab the live URL (e.g. `yourproject.vercel.app`)
- [ ] **Send the link:**
  - [ ] DM, email, or video walkthrough with the link
  - [ ] One client per city, mention it
- [ ] **Optional: connect a custom domain via Namecheap (~$12/year)**

## Notes

- Build pages for top 3 niches BEFORE launching outreach. Conversion on replies doubles when the niche page already exists vs scrambling after.
- Authority page (your personal page) is separate: photo, headline positioning you for specific niches in specific region, three target industries, Process, AI Arbitrage System, exclusivity, About, final CTA. Same dark mode + blue accent specs.
- You can launch authority page without case studies by leading with mechanism (AI Arbitrage System) and process.
- Each niche page is reusable for every prospect in that niche, just swap business name + scarcity line.
