# Daily 15-Minute Optimization Routine

**Category:** Optimization
**Source:** Module 3 Lesson 11
**When to use:** Every day per active client. The single most important recurring SOP.
**Estimated time:** 15 min per client

---

## Prerequisites

- [ ] Campaign live for at least 3 days (out of learning phase)
- [ ] Target CPL agreed with client
- [ ] Daily tracking sheet ready

## Checklist

- [ ] **Scan (0:00 to 3:00):**
  - [ ] Open Ads Manager, set date range to yesterday
  - [ ] Pull metrics for each ad: spend, leads, CPL, CTR, CPM, frequency
  - [ ] Observe only. Do not edit anything yet.
- [ ] **Decide (3:00 to 7:00). Label each ad:**
  - [ ] KILL: CPL at 3x+ target. Drains spend, no recovery expected. (Wait until ad has spent 2 to 3x target CPL before judging.)
  - [ ] WATCH: CPL 1.5x to 3x target. Give 2 to 3 more days.
  - [ ] SCALE: CPL at or below target. Increase budget 20 to 30%.
  - [ ] REFRESH: Frequency 3.0+. Add 3 to 5 new creatives, don't pause existing.
- [ ] **Execute (7:00 to 12:00):**
  - [ ] Pause all KILL ads
  - [ ] Increase budgets on SCALE ads by 20% max (more triggers learning phase reset)
  - [ ] Queue creative refresh for REFRESH ads (don't pause)
  - [ ] Note WATCH ads for tomorrow
- [ ] **Log (12:00 to 15:00):**
  - [ ] Update daily tracking sheet: date, spend, leads, CPL, CTR, CPM, frequency, decision, notes
  - [ ] Add change log entry for any pauses, budget increases, or creative adds (used in weekly report)

## Notes

- The #1 beginner mistake is over-optimizing. Meta needs ~50 conversions in the learning phase. Frequent changes reset progress.
- Significant edits (budget change over 20%, new creative, audience modifications) restart Learning. Batch optimizations together to minimize restarts.
- Never edit the winning ad. Performance dies on revision. Test variations as separate ads.
- Never double budget overnight. $15 to $30 confuses the algorithm. Use the ladder: $15 to $18 to $22 to $27 with 2 to 3 days between increments.
- Never optimize based on feelings. Only the data decides what stays and what goes.
