# Generate Ad Copy Using 12-Angle Rule

**Category:** Creative
**Source:** Module 3 Lesson 8
**When to use:** Every new creative round. Day 3 of onboarding, and every creative refresh.
**Estimated time:** 30 min (10 min generation, 12 min editing)

---

## Prerequisites

- [ ] Client brief file ready (`clients/[name].md`) with business info, voice, current offer, past winners
- [ ] Aurelius prompt template ready
- [ ] Niche identified

## Checklist

- [ ] **List 12 distinct reasons to buy.** Each is a different motivation, fear, or angle. Examples for a pizza shop:
  - [ ] Too tired to cook (pain)
  - [ ] Family Friday (desire)
  - [ ] Half the price of delivery apps (logic)
  - [ ] Real Italian (quality)
  - [ ] 20-min delivery (convenience)
  - [ ] 400+ 5-star reviews (social proof)
  - [ ] New in the area (discovery)
  - [ ] Party catering (occasion)
  - [ ] Healthy option (health)
  - [ ] Easy ordering (simplicity)
  - [ ] Late night (timing)
  - [ ] Limited special (urgency)
- [ ] **Assign a framework to each angle:**
  - [ ] PAS (Problem-Agitate-Solution) for pain-aware audiences
  - [ ] AIDA (Attention-Interest-Desire-Action) for offer-driven angles
  - [ ] BAB (Before-After-Bridge) for transformation
  - [ ] Story (Character-Conflict-Resolution) for emotional UGC
- [ ] **Run Aurelius:**
  - [ ] Paste mega prompt with client info
  - [ ] Request 12 ads, one per angle, organized by framework
  - [ ] Specify length mix (short under 50 words, medium 50-100, long 100+)
- [ ] **Run the 60-second edit on each ad:**
  - [ ] Read aloud, does it sound like a real person?
  - [ ] First line stops the scroll?
  - [ ] Kill AI words: elevate, transform, seamless, leverage, robust, game-changing
  - [ ] Replace vague with specific: "many" becomes "73%", "soon" becomes "by Friday", "affordable" becomes "$12.99"
  - [ ] Match the client's actual voice, not generic AI
- [ ] **Check against the 6 AI anti-patterns and rewrite if any appear:**
  - [ ] "Not X, it's Y" contrast structure
  - [ ] Triple structure ("Fresh ingredients. Fast delivery. Unbeatable prices.")
  - [ ] "Imagine this" opener
  - [ ] Filler power words ("game-changing", "extraordinary")
  - [ ] Question-then-answer sequence
  - [ ] Perfect grammar robot tone (too polished, too clean)
- [ ] **Save to client folder** under `clients/[name]/creatives/copy-[date].md`

## Notes

- One ad equals one reason to buy. Twelve angles, not twelve rewrites of the same headline. This is the rule that changes everything.
- Long copy isn't dead. Story-format 100+ word ads outperform short for emotional niches.
- After a campaign runs, log winners back to client file under Proven Winners with hook, CTR, CPL, and why it worked.
