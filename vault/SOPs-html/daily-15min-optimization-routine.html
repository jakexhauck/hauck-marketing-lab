Notes

  • The #1 beginner mistake is over-optimizing. Meta needs ~50 conversions in the learning phase. Frequent changes reset progress.
  • Significant edits (budget change over 20%, new creative, audience modifications) restart Learning. Batch optimizations together to minimize restarts.
  • Never edit the winning ad. Performance dies on revision. Test variations as separate ads.
  • Never double budget overnight. $15 to $30 confuses the algorithm. Use the ladder: $15 to $18 to $22 to $27 with 2 to 3 days between increments.
  • Never optimize based on feelings. Only the data decides what stays and what goes.
