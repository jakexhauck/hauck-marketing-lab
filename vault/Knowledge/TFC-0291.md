# Challenge Day 3 Segmentation

## TL;DR (Heuristico)
Day 3 (2-3h): Conteudo avancado + breakout + repitch. Meta: "Preciso agir AGORA."

## Guia Rapido
> Regra de ouro: "Segmentar = falar a coisa certa pra pessoa certa"

### Checklist Day 3
- [ ] 3 breakout rooms configuradas?
- [ ] Co-host em cada room?
- [ ] Buyers separados imediatamente?
- [ ] Bonus final para urgencia?

---

## Framework Detalhado (Analitico)

### Schedule
```
00:00-00:20  Energia + commitment
00:20-01:15  Conteudo avancado/exclusivo
01:15-02:00  BREAKOUT ROOMS
02:00-02:45  Repitch non-buyers
```

### Breakout Strategy
| Room | Audiencia | Conteudo |
|------|-----------|----------|
| A | High-earners | Premium $25K+ |
| B | Main audience | Core offer repitch |
| C | Buyers | Afirmacao, reduz remorse |

### Room C - Buyer Affirmation
```
1. Parabens pela decisao
2. Entrega imediata de valor
3. Definir expectativas
4. Construir excitacao
5. Reduzir risco de refund
```

---

## Padroes e Insights (Intuitivo)

### Analogia
> "Breakout rooms sao como balcoes diferentes numa loja - quem quer Rolex nao fica no mesmo lugar de quem quer Casio"

### Padroes
- Buyers em sala separada = -50% refunds
- High-earner room = 10-20% premium conversions
- Se nao segmenta, perde vendas premium

---

## Armadilhas (Critico)

### Red Flags
- Nunca deixe buyers ouvindo objecoes de nao-buyers
- Se breakout nao tem co-host, caos
- Se nao pre-designou rooms, atraso

### Erros Comuns
```
ERRO: Buyers vendo repitch
FIX: Mova buyers IMEDIATAMENTE apos compra

ERRO: Mesmo pitch pra todos
FIX: Personalizar por room
```

---

## Variacoes (Criativo)
- VIP room para high-ticket ($50K+)
- 1:1 follow-up para leads quentes
- "Surprise bonus" so para quem ficou ate o fim

---

## Key Points
- Segmente por compra + income
- Mova buyers imediatamente
- High-earner room = 10-20% premium
- Day 3 = ultima chance urgency
