# Creative Fatigue Detection

## TL;DR
CTR -20% or CPM +30% over 7 days = fatigue. Frequency >2.5 = urgent refresh. Add 10-20 new creatives, don't just tweak.

## Primary Fatigue Signals

| Signal | Threshold | Severity |
|--------|-----------|----------|
| CTR drop | -20% / 7 days | Medium |
| CTR drop | -30% / 7 days | High |
| CPM rise | +30% / 7 days | Medium |
| CPM rise | +50% / 7 days | High |
| Frequency | > 2.5 | Medium |
| Frequency | > 3.5 | Critical |

## Secondary Signals

- Video watch time declining
- Shares/saves decreasing
- Comments going negative
- ThruPlay % dropping
- CPA creeping up steadily

## Fatigue Levels

### Level 1: Early Warning
```
CTR down 10-20%, Frequency 2.0-2.5

ACTION:
- Add 5-10 new creatives
- Pause bottom 20%
- Test new hooks (same angles)
```

### Level 2: Moderate
```
CTR down 20-30%, Frequency 2.5-3.0

ACTION:
- Add 15+ new creatives
- Introduce new angles
- Consider new formats
- Pause 30% of creatives
```

### Level 3: Severe
```
CTR down 30%+, Frequency > 3.0

ACTION:
- Complete creative overhaul
- All new angles
- New formats
- New messaging strategy
```

## Refresh Protocol

| Level | Creatives Needed | Timeline |
|-------|------------------|----------|
| Early | 5-10 new | This week |
| Moderate | 15+ new | Immediate |
| Severe | 20+ completely new | ASAP |

## The CPM Problem

```
"My CPMs are $40 and climbing"

WRONG DIAGNOSIS: "Targeting is off"
RIGHT DIAGNOSIS: "Not enough creative diversity"

WRONG SOLUTION: "Change targeting"
RIGHT SOLUTION: "Add 20 more unique creatives"
```
