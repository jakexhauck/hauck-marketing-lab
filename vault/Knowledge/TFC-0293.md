# Challenge Ad Strategy

## TL;DR (Heuristico)
4 frameworks criativos, 3 tiers de audiencia, teste 5-10 conceitos, escale winners 20-30%/semana.

## Guia Rapido
> Regra de ouro: "CPR target $15-30, mate losers em 3 dias"

### Checklist Ads
- [ ] 5+ conceitos criativos?
- [ ] Warm + LAL + Cold separados?
- [ ] Budget por ad set $100-500/dia?
- [ ] Metrica = CPP (cost per purchase)?

---

## Framework Detalhado (Analitico)

### Creative Frameworks
| Framework | Hook Exemplo |
|-----------|--------------|
| Event | "Junte-se a 5,000+ no [Nome]" |
| Behind Scenes | "Primeira vez revelando..." |
| Challenge | "Acha que nao consegue? Te desafio" |
| Transformation | "De X para Y em 72h" |

### Audience Tiers
```
WARM: Email, buyers, visitors, engagers
LAL 1%: Buyers, high-ticket, call shows
COLD: Broad + age/geo, interests
```

### Testing Process
| Passo | Acao | Timing |
|-------|------|--------|
| 1 | Criar 5-10 conceitos | D-21 |
| 2 | $100-500/dia por ad set | D-14 |
| 3 | Testar 3-5 dias | D-14 a D-9 |
| 4 | Medir CPP, nao clicks | D-9 |
| 5 | Escalar winners, matar losers | D-9+ |

### Scaling Rules
- Max 20-30% aumento/semana
- Monitore qualidade, nao so volume
- Rotacione criativos (fatigue)
- Adicione audiencias gradualmente

---

## Padroes e Insights (Intuitivo)

### Analogia
> "Ads e como pescar - primeiro acha onde os peixes estao (audiencia), depois testa iscas (criativos)"

### Padroes
- Video > imagem geralmente
- Se CPR > $50, criativo ou audiencia ruim
- Warm audience sempre converte melhor

---

## Armadilhas (Critico)

### Red Flags
- Nunca escale mais de 30%/semana
- Se ad set nao performa em 3 dias, mate
- Nao olhe so clicks, olhe purchases

### Erros Comuns
```
ERRO: Escalar rapido demais
FIX: Max 20-30%/semana

ERRO: Otimizar para clicks
FIX: Sempre CPP (cost per purchase)
```

---

## Variacoes (Criativo)
- UGC (user generated content) ads
- "Day in the life" criativos
- Testimonial video hooks

---

## Key Points
- CPR target: $15-50
- Qualidade > quantidade
- Video > imagem
- Retargeting e crucial
