# Challenge Funnel Economics

## TL;DR (Heuristico)
Challenge funnels: $200K+ ad budget, 8 semanas, 1.5-2.5x front ROAS, 5-15x total ROAS. Paid = 70% show rate.

## Guia Rapido
> Regra de ouro: "Front-end paga os ads, back-end e o lucro"

### Checklist Pre-Challenge
- [ ] Budget minimo $200K confirmado?
- [ ] 8 semanas de runway?
- [ ] OTOs configurados (3 niveis)?
- [ ] Main offer pronto ($5K-$25K)?

---

## Framework Detalhado (Analitico)

### Case Study $4M
| Metrica | Valor |
|---------|-------|
| Ad spend | $292K |
| Tickets | $554K (1.9x) |
| Registros | 6,000+ |
| Show rate | 70% |
| Challenge rev | $3.4M |
| Main offer | $10K |

### Target Metrics
| Metrica | Target | Aceitavel | Ruim |
|---------|--------|-----------|------|
| CPR | $15-30 | $30-50 | >$50 |
| Show Rate | >70% | 50-70% | <50% |
| Conversao | 10-15% | 5-10% | <5% |
| Front ROAS | 2x+ | 1.5-2x | <1.5x |
| Total ROAS | 10x+ | 5-10x | <5x |

### Estrutura OTO
```
OTO1: $100-150 → 15% CVR
OTO2: $200-300 → 10% CVR
OTO3: $400-600 → 7% CVR
TOTAL adicional: ~$80/registrante
```

---

## Padroes e Insights (Intuitivo)

### Analogia Principal
> "Challenge funnel e como show de rock - voce vende ingresso barato pra lotar, e lucra na cerveja e camiseta (back-end)"

### Padroes Reconheciveis
- Se front ROAS > 2x, escala agressivo
- Se show rate < 50%, problema e no pre-evento
- Se conversao < 5%, pitch ou offer precisam ajuste

---

## Armadilhas e Erros (Critico)

### Red Flags
- Se ad budget < $100K, NAO faca challenge
- Nunca lance sem 8 semanas de promocao
- Se show rate < 40%, pause e corrija

### Erros Comuns
```
ERRO: Calcular ROAS so no front-end
FIX: Sempre calcule ROAS total (front + main offer)

ERRO: Challenge gratuito para audiencia fria
FIX: Paid challenge ou aqueca antes
```

---

## Variacoes (Criativo)
- B2B: Ticket $297, offer $25K+
- Low-ticket: Challenge $27, offer $997-$2K
- Combina com: (ref: TFC-0292) SMS para +15% show

---

## Key Points
- Minimo $200K ad budget
- 8 semanas de promocao
- Paid > Free (70% vs 30% show)
- Front-end = break-even, back-end = lucro
