# Ad Copy Prompt Library

Paste-ready prompts. Fill in the brackets, paste into Claude.

# Mega Prompt Builder (the brief)

Always start by filling this out for the client. Save it to `vault/Clients/[name]/Profile.md` if not already there.

```
- Business Name: [blank]
- What they sell / do: [blank]
- Target Customer: [blank]
- What makes them different (USP): [blank]
- Current Offer / Promotion: [blank]
- Tone / Voice: [Casual & Friendly / Professional / Urgent & Direct / Luxury & Premium / Fun & Playful / Local & Community]
- Platform: [FB + IG Ads / Google Ads / TikTok Ads]
```

# Core prompts

## 1. Basic generation (5 variations)
> write 5 facebook ad variations for [client name]. the goal is [leads / store visits / sales]. the offer is [what they're promoting]. give me the hook, primary text, headline, and CTA for each.

## 2. Hook batch (10 hooks)
> i need 10 scroll-stopping hooks for [client name]'s [offer]. target audience: [who]. angle: [problem-aware / solution-aware / unaware]. make half question-based and half pattern interrupts. keep them under 15 words each.

## 3. Creative concepts (visual + copy)
> give me 5 ad creative concepts for [client name]. for each one describe: the visual (what the image or video should show), the hook text overlay, the primary text, the headline. format it so i can hand this to a designer or film it myself.

## 4. UGC script (30 seconds)
> write a 30-second UGC script for [client name]. format: person talking to camera, casual, like a real testimonial. the hook has to work in the first 2 seconds. include camera directions in [brackets]. the CTA should feel natural, not salesy.

# Iteration prompts (always run at least one)

## Round 2: punch it up
> these are my top 3. make each one punchier. shorter sentences. stronger hooks. remove anything that sounds like AI wrote it.

## Round 3: angle multiplication
> now give me 3 different angles for each of these. same offer, different emotional triggers. one focused on fear of missing out. one focused on aspiration. one focused on solving a specific pain point.

## Anti-AI pass
> rewrite these to remove the 6 AI anti-patterns: "not X it's Y" contrasts, triple structures, "imagine this" openers, filler power words (elevate/transform/unlock), question-then-answer, perfect grammar. read each one aloud, if you'd cringe hearing a real person say it, rewrite it.

# Framework-specific prompts

## PAS pain ad
> write a PAS framework facebook ad for [client name]. pain point: [specific pain]. agitate by listing 2-3 specific consequences. solution: [client offer]. 50-80 words. punchy. mobile-readable. end with clear CTA.

## AIDA offer ad
> write an AIDA framework facebook ad for [client name]'s [offer]. lead with a scroll-stopping attention line. build interest with 1-2 specific proof points. create desire with the transformation. end with urgency CTA. 60-100 words.

## BAB transformation ad
> write a BAB framework facebook ad for [client name]. before: [current painful situation]. after: [desired state]. bridge: [how the offer gets them there]. 70-100 words. specific scenarios, no abstractions.

## STORY UGC ad
> write a STORY framework facebook ad for [client name]. character: [relatable customer type]. conflict: [their struggle]. resolution: [how client solved it]. write like you're telling a friend over coffee. 80-120 words.

# 12-Angle batch (one ad per angle)
> using [client name]'s offer, write 12 facebook ads, one for each of these angles: 1) pain/exhaustion 2) family/quality time 3) price/value 4) authenticity/quality 5) speed/convenience 6) social proof/reviews 7) discovery/local 8) occasion/event 9) health/guilt-free 10) ease/simplicity 11) timing 12) urgency/scarcity. each ad must use a DIFFERENT framework from PAS/AIDA/BAB/STORY. 40-60 words each.
