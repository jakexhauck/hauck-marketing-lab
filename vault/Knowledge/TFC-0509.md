# DSL Revolution Framework

## TL;DR
Disrupt-Story-Landing structure for video ads. First 3 seconds = hook or die. Media Buying Expert methodology.

## The DSL Structure

```
D = DISRUPT (0-3 sec) → Stop the scroll
S = STORY (3-45 sec) → Build connection
L = LANDING (45-60 sec) → Drive action
```

## DISRUPT Phase (Critical)

**Purpose:** Pattern interrupt, stop the scroll
**Time:** 0-3 seconds
**Make or break:** If this fails, nothing else matters

**Formats:**
- "Wait, what?"
- "Nobody told you this..."
- "Stop scrolling if..."
- Visual surprise
- Unexpected statement

## STORY Phase

**Purpose:** Build connection and credibility
**Time:** 3-45 seconds

**Structure:**
1. **Before state** (0:03-0:13): Relatable pain
2. **Discovery** (0:13-0:25): Turning point
3. **Transformation** (0:25-0:35): The change
4. **Proof** (0:35-0:45): Results, testimonials

**Requirements:**
- Specific details (names, numbers, dates)
- Emotional connection
- Builds to solution
- Maintains attention

## LANDING Phase

**Purpose:** Clear CTA with urgency
**Time:** 45-60 seconds

**Formats:**
- "Click the link below"
- "Comment [word] and I'll send..."
- "Register now before..."
- "Limited spots available"

## Script Lengths

| Format | Duration | Use Case |
|--------|----------|----------|
| Quick DSL | 15-30 sec | Retargeting, simple offers |
| Standard DSL | 45-60 sec | Primary ads, new audiences |
| Extended DSL | 90-120 sec | Complex offers, education |

## DSL + 100 Hook Framework

Combine DSL structure with hook categories:
1. Choose hook from 100 Framework
2. Build D around hook
3. Construct S to support hook angle
4. Match L to hook energy
