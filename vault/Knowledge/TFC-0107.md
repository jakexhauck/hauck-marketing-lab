# Andromeda Campaign Structure

## TL;DR
December 2024 changed everything. 1-2 campaigns max, 15-25+ diverse creatives per ad set, broad targeting, Advantage+ default. Old segmentation is dead.

## What Changed (December 2024)

Meta's Andromeda system with NVIDIA Grace Hopper:
- **10,000x** more ad candidates processed
- **100x** faster processing
- **+22% ROAS** with Advantage+ campaigns
- **+8%** ad quality improvement

## OLD WAY (Deprecated)

```
5+ campaigns
├── 5+ ad sets per campaign
│   └── 3-6 creatives per ad set
├── Complex micro-segmentation
├── Lookalike audiences
└── Manual targeting

STATUS: DOES NOT WORK ANYMORE
```

## NEW WAY (Mandatory)

```
1-2 campaigns MAXIMUM
├── 1-3 broad ad sets
│   └── 15-25+ DIVERSE creatives
├── Broad or NO targeting restrictions
├── Advantage+ as default
└── Trust the algorithm

STATUS: REQUIRED for results
```

## Mandatory Architecture

| Element | Requirement |
|---------|-------------|
| Campaigns | 1-2 maximum |
| Ad Sets | 1-3 per campaign |
| Creatives | 15-25+ per ad set |
| Targeting | Broad (minimal restrictions) |
| Campaign Type | Advantage+ default |
| Budget | CBO preferred |
| Placements | Automatic (Advantage+) |

## Creative Requirements

```
OLD: 3-6 creatives per week
NEW: 50+ creative variations per month

OLD: "Rule of 6" per ad set
NEW: 15-25+ diverse creatives per ad set

The "rule of 6" died in February 2025.
```

## Diversification Rule

**BAD (Same angle):**
- "Save money" → "Save cash" → "Cut costs"

**GOOD (Different angles):**
- "Healthier ingredients" (health)
- "Stop expensive vet visits" (financial)
- "Dog will finally eat" (palatability)

## What NOT to Do

```
❌ 5+ campaigns for same offer
❌ Multiple similar ad sets
❌ Interest-based targeting
❌ Lookalike as primary audience
❌ Less than 10 creatives per ad set
❌ Minor variations of same angle
```
