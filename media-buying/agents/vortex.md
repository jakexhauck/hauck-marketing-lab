## THE 100 HOOK FRAMEWORK

Seven categories, 100+ hooks. Use diverse categories for maximum algorithm performance.

### Category 1: Urgency & Scarcity (Hooks 1-15)
```
Templates:
- "Only [X] spots left for [event]"
- "[X] hours until [deadline]"
- "This won't be available after [date]"
- "I'm pulling this down in [timeframe]"
- "Last chance to [benefit]"

Example hooks:
1. "47 spots left. When they're gone, they're gone."
2. "In 72 hours this video disappears forever."
3. "I'm only doing this once. Here's why..."
```

### Category 2: Social Proof & Authority (Hooks 16-30)
```
Templates:
- "[Number] people already [achieved result]"
- "After [X years/clients], I discovered..."
- "[Famous person/company] uses this exact..."
- "I've helped [number] [audience] to [result]"
- "[Credibility marker] reveals..."

Example hooks:
16. "2,847 students. Same method. Same results."
17. "After 10 years in the trenches..."
18. "The strategy Goldman Sachs doesn't want you to know"
```

### Category 3: Problem Agitation (Hooks 31-45)

```
Templates:

- "Stop [ineffective action] right now"

Example hooks:
31. "Tired of throwing money at ads that don't convert?"
32. "If your CPMs are climbing, watch this NOW."

```

### Category 4: Curiosity Gap (Hooks 46-60)

### Category 5: Transformation & Outcome (Hooks 61-75)

### Diversification Rules
Each creative MUST target a DIFFERENT psychological motivation:

**BAD Example (same angle, minor variations):**
- "Save money on dog food" (headline A)
- "Save cash on dog food" (headline B)
- "Cut costs on dog food" (headline C)
→ SAME ANGLE = ALGORITHM PENALTY

**GOOD Example (different motivations):**
- "Healthier ingredients for your dog" (health angle)
- "Stop expensive vet visits" (financial angle)
- "Your dog will finally eat everything" (palatability angle)
- "Vet-approved nutrition" (authority angle)
→ DIFFERENT ANGLES = ALGORITHM REWARD

## DSL REVOLUTION FRAMEWORK (Expert Source B)

### DSL Structure
```
D = Disrupt (Hook - first 3 seconds)
S = Story (Connect - middle section)
L = Landing (CTA - close)
```

### DSL Script Template
```
[DISRUPT - 0:00-0:03]
{Pattern interrupt hook from 100 Hook Framework}

[STORY - 0:03-0:45]
"Here's what happened..."
- Paint the before picture
- The discovery/turning point
- The transformation
- The proof

[LANDING - 0:45-0:60]
"Here's what I want you to do..."
- Clear CTA
- Urgency element
- Risk reversal
```

### DSL Variations
```
DSL-Short (15 sec): Hook + Mini-story + CTA
DSL-Standard (30-60 sec): Full structure
DSL-Long (90-120 sec): Extended story + multiple proof points
```

## CREATIVE FATIGUE DETECTION

### Warning Signs
| Signal | Threshold | Action |
|--------|-----------|--------|
| CTR dropping | -20% over 7 days | Generate new hooks |
| CPM climbing | +30% over 7 days | Need creative diversity |
| Frequency > 2.5 | Any campaign | Refresh urgently |
| Engagement dropping | -30% over 7 days | New angles needed |

### Refresh Protocol
```
LEVEL 1 (Minor fatigue):
- New headlines on existing creative
- New CTA variations
- New thumbnail/first frame

LEVEL 2 (Moderate fatigue):
- New hook angles (different category)
- New story angles
- New visual style

LEVEL 3 (Severe fatigue):
- Complete creative overhaul
- New formats (static → video, video → carousel)
- New messaging strategy
- New offer framing
```
