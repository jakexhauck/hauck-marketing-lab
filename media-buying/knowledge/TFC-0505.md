# Traffic Command System Overview

## TL;DR
Multi-agent traffic management system with 5 specialized agents (Aurelius, Zenith, Vortex, Nexus, Stratos), 18 skills, and 47 expert frameworks. Built for Andromeda era (Dec 2024+).

## Architecture

```
CMO
     ↓
AURELIUS (Traffic Commander)
     ↓
┌────────┬────────┬────────┬────────┐
ZENITH   VORTEX   NEXUS    STRATOS
Metrics  Creative Tracking Strategy
```

## Agent Roles

| Agent | Codename | Primary Function |
|-------|----------|------------------|
| Aurelius | The Golden Strategist | Lead, orchestrate, approve |
| Zenith | Peak Performance | Metrics, kill/scale, budget |
| Vortex | Creative Pull | Hooks, briefs, copy, DSL |
| Nexus | Connection Hub | Pixel, CAPI, tracking |
| Stratos | High-Altitude View | Strategy, economics, scaling |

## Skill Categories (18 Total)

- **Strategic (4)**: campaign-structure, funnel-selection, scale-readiness-check, unit-economics
- **Diagnostic (5)**: metric-diagnosis, tracking-audit, funnel-analysis, attribution-analysis, creative-fatigue-detector
- **Generative (5)**: hook-generator, copy-generator, creative-brief, angle-generator, dsl-structure
- **Optimization (3)**: kill-scale-rules, budget-allocation, audience-expansion
- **Automation (1)**: campaign-monitor

## Workflow Chains

**Launch Chain:**
stratos (economics) → stratos (funnel) → aurelius (structure) → vortex (brief) → nexus (audit) → aurelius (launch)

**Optimize Chain:**
zenith (diagnosis) → zenith (kill/scale) → zenith (budget) → [vortex OR nexus] → aurelius (approve)

**Scale Chain:**
stratos (readiness) → zenith (budget) → zenith (expansion) → aurelius (approve)
