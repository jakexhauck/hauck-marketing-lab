# Paid Traffic Strategy - Scaling Ads

## TL;DR (Heuristico)
Ads facilitam vendas, nao substituem. Aquecer leads antes da call. Escala = criativo forte + oferta validada + processo testado.

## Guia Rapido
> Regra de ouro: "Oferta ruim + ads perfeitos = fracasso"

### Checklist Ads
- [ ] Oferta validada antes de escalar?
- [ ] Criativo testado com budget baixo?
- [ ] ROAS minimo 3:1 atingido?
- [ ] LTV:CAC ratio >3:1?

---

## Framework Detalhado (Analitico)

**Hierarquia de Sucesso em Ads:**
```
1. OFERTA (mais importante)
   |
2. CRIATIVO
   |
3. COPY
   |
4. TARGETING
   |
5. TECNICO (menos importante)

"Oferta ruim + ads perfeitos = fracasso"
```

**Papel dos Ads no Funil:**
```
ADS NAO VENDEM - ADS AQUECEM

Funcao real:
- Gerar atencao
- Qualificar interesse
- Aquecer antes da call
- Facilitar trabalho do closer

Se closer precisa "vender duro",
ads nao fizeram o trabalho
```

**Framework de Escala:**

| Fase | Budget | Objetivo |
|------|--------|----------|
| Teste | R$50-100/dia | Validar criativo |
| Validacao | R$200-500/dia | Confirmar CAC |
| Escala | R$1K+/dia | Maximizar volume |
| Otimizacao | Variavel | Melhorar ROAS |

**Estrutura de Campanha:**
```
CAMPANHA (Objetivo)
|
+-- AD SET 1 (Lookalike)
|   +-- Ad A (Video)
|   +-- Ad B (Imagem)
|   +-- Ad C (Carrossel)
|
+-- AD SET 2 (Interest)
|   +-- Ad A, B, C
|
+-- AD SET 3 (Retargeting)
    +-- Ad D, E, F
```

**Metricas de Ads:**
```
CUSTO:
- CPM: Custo por 1000 impressoes
- CPC: Custo por clique
- CPL: Custo por lead

QUALIDADE:
- CTR: Taxa de clique (>1.5%)
- Hook rate: Retencao 3 seg (>30%)
- Hold rate: Retencao total

RESULTADO:
- CAC: Custo de aquisicao
- ROAS: Return on ad spend
- LTV:CAC ratio (>3:1)
```

---

## Padroes e Insights (Intuitivo)

### Analogia
> "Ads sao como agua quente - preparam o lead para o closer cozinhar"

### Padroes
- Se closer precisa vender duro, ads falharam
- CTR <1.5% = criativo fraco
- Hook rate <30% = primeiros 3 seg ruins

---

## Armadilhas (Critico)

### Red Flags
- Nunca escale sem validar oferta primeiro
- Nunca jogue dinheiro em ads com ROAS <3:1
- Nunca culpe targeting se oferta e fraca

### Erros Comuns
```
ERRO: Escalar ads sem validar oferta
FIX: Validar com R$50-100/dia primeiro

ERRO: Focar em targeting antes de criativo
FIX: Hierarquia: Oferta > Criativo > Copy > Targeting

ERRO: Esperar que ads facam a venda
FIX: Ads aquecem, closer vende
```

---

## Variacoes (Criativo)
- UGC ads (user-generated content)
- Retargeting agressivo pos-webinar
- Lookalike de compradores (nao so leads)

---

## Key Points
- Oferta > Criativo > Copy > Targeting
- Ads aquecem, nao vendem
- Testar com budget baixo antes de escalar
- ROAS minimo 3:1 para escalar
