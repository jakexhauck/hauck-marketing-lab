# Unit Economics Calculator

## TL;DR
LTV > 3x CAC minimum. Break-even within 30-60 days. Front-end pays ads, back-end is profit. From Business Expert + Media Buying Expert.

## Core Formulas

```
CAC = Total Marketing Spend / New Customers
LTV = AOV × Purchase Frequency × Customer Lifespan
ROAS = Revenue / Ad Spend
MER = Total Revenue / Total Marketing Spend
```

## The Golden Rules ([Expert])

| Rule | Requirement |
|------|-------------|
| LTV/CAC Ratio | > 3x minimum |
| Break-even | Within 30-60 days |
| Back-end Value | 3-5x front-end |

## Front-End vs Back-End ([Expert])

```
FRONT-END:
- Purpose: Acquire customer, break even
- Target ROAS: 1.5-2.5x
- Timeline: Immediate to 7 days

BACK-END:
- Purpose: Generate profit
- Target ROAS: 5-15x
- Timeline: 30-90 days

"Front-end pays the ads, back-end is the profit"
```

## LTV Calculation

```
LTV (90-day) =
  Front-end revenue
  + (Upsell 1 × take rate)
  + (Upsell 2 × take rate)
  + (Back-end × conversion rate)
  + (Recurring × months retained)
```

## Target CPA Formula

```
Target CAC = LTV / 3

Example:
LTV: R$640
Target CAC: R$640 / 3 = R$213
```

## Brazilian Adjustments

- **Installments:** Most pay 12x (40% immediate cash)
- **Taxes:** 6-15% depending on structure
- **Gateway fees:** 4-6%
- **Net margin:** Listed price × 0.80-0.85
