# Show Rate Optimization

## TL;DR (Heuristico)
Target 70%+ via multi-channel + pre-event value. Paid = 70%, Free = 30-40%.

## Guia Rapido
> Regra de ouro: "SMS no dia = +15% show rate"

### Checklist Show Rate
- [ ] Calendar invite automatico?
- [ ] Sequencia de emails pronta?
- [ ] SMS configurado (D-1, D-0)?
- [ ] Pre-event value entregue?

---

## Framework Detalhado (Analitico)

### Communication Sequence
| Timing | Canal | Conteudo |
|--------|-------|----------|
| Imediato | Email | Confirm + calendar |
| Day 1 | Email | Welcome video |
| Day 2 | Email | Success story |
| Day 3 | Email | Prep guide |
| -7 days | Email | Final details |
| -3 days | Email | Tech instructions |
| -1 day | Email+SMS | Final reminder |
| -1 hour | Email+SMS | "Starting soon" |
| -15 min | All | "Join now" |
| Start | Email | "We're live" |

### Show Rate Factors
| Fator | Impacto |
|-------|---------|
| Paid vs Free | +30-40% |
| SMS reminders | +10-15% |
| Pre-event value | +5-10% |
| Community | +5-10% |

---

## Padroes e Insights (Intuitivo)

### Analogia
> "Show rate e como confirmacao de reserva - quanto mais lembra, mais aparece"

### Padroes
- Open rate emails < 30% = problema no subject
- Se SMS nao tem link direto, perde 50% dos clicks
- Paid challenge = compromisso financeiro = aparece

---

## Armadilhas (Critico)

### Red Flags
- Se show rate < 50%, pause e corrija
- Nunca dependa so de email
- Se nao tem SMS, esta perdendo 15%

### Erros Comuns
```
ERRO: So email, sem SMS
FIX: SMS D-1 e D-0 obrigatorios

ERRO: Calendar invite manual
FIX: Automatizar no registro
```

---

## Variacoes (Criativo)
- WhatsApp group para comunidade
- "Bonus surpresa" para quem entra cedo
- Countdown timer no email

---

## Key Points
- Paid = 70%+, Free = 30-40%
- SMS critico nos lembretes finais
- Pre-event value = compromisso
- Calendar invite obrigatorio
