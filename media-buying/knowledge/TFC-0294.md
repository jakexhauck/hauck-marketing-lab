# Challenge Troubleshooting

## TL;DR (Heuristico)
Referencia rapida para problemas comuns e solucoes imediatas.

## Guia Rapido
> Regra de ouro: "Se algo pode dar errado, vai dar. Tenha backup."

### Checklist Emergencia
- [ ] Backup Zoom pronto?
- [ ] Link alternativo disponivel?
- [ ] Team pode resolver sem voce?

---

## Framework Detalhado (Analitico)

### Problem → Solution Matrix
| Problema | Causa | Solucao |
|----------|-------|---------|
| Low registrations | Headline fraca | Test new angles |
| Low registrations | Audiencia errada | Refine targeting |
| Poor show rate | Pre-event fraco | Add value before |
| Poor show rate | Challenge free | Consider paid |
| Low engagement | Content mismatch | Adjust level |
| Low engagement | No interaction | Add polls/chat |
| Poor conversion | Pitch fraco | More social proof |
| Poor conversion | Offer errado | Adjust price/value |
| Tech failures | Sem prep | Multiple backups |
| High refunds | Oversold | Align expectations |
| High refunds | Slow delivery | Faster value |

### Pre-Launch Checklist
```
[ ] Zoom tested + backup link
[ ] Recording verified
[ ] Breakouts configured
[ ] Presentations final
[ ] Emails/SMS loaded
[ ] Ads performing
[ ] Team briefed
```

### Day-Of Checklist
```
[ ] T-4h: Full tech check
[ ] T-1h: Zoom live, musica
[ ] T-15m: Final reminder sent
[ ] T-0: Recording started
```

---

## Armadilhas (Critico)

### Red Flags Tecnicos
- Se Zoom cair, tenha segundo link pronto
- Se audio falhar, tenha mic backup
- Se apresentacao corromper, tenha PDF backup

### Erros Comuns
```
ERRO: Confiar que vai dar tudo certo
FIX: Backup para TUDO

ERRO: Nao testar 24h antes
FIX: Full rehearsal obrigatorio

ERRO: Nao documentar problemas
FIX: Post-mortem apos cada challenge
```

### Crisis Protocol
```
PROBLEMA: Zoom caiu
ACAO IMEDIATA:
1. Post no chat "Estamos resolvendo, 2 min"
2. Ativar backup link
3. Email emergencia com novo link
4. Continuar sem perder ritmo
```

---

## Key Points
- Sempre tenha backup Zoom
- Teste tudo 24h antes
- Comunicacao do time e critica
- Documente problemas para proxima vez
