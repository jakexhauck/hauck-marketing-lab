# Kill/Scale Rules Framework

## TL;DR
Data-driven rules for killing losers fast and scaling winners slow. 72-hour minimum, $500 spend minimum, 20% max increase. From Performance Expert + Media Buying Expert.

## Core Philosophy

```
"Data before emotion"
"Kill fast, scale slow"
"72 hours minimum before judging"
```

## Kill Rules (Any = Kill)

| Condition | Threshold | Minimum Data |
|-----------|-----------|--------------|
| CPA vs Target | > 2x target | 72h, $500 |
| CTR | < 0.5% | 5,000 impressions |
| Conversions | Zero | $300 spend |
| CVR | < 0.5% | 200 clicks |
| ROAS | < 0.5x | 5+ days |
| Frequency | > 3.5 + declining | Any |

## Scale Rules (All = Scale)

| Condition | Requirement |
|-----------|-------------|
| CPA | < target for 72h+ |
| CTR | > 1.2% consistently |
| CVR | > 2% |
| ROAS | > 2x for 5+ days |
| Spend | > $1,000 in test |
| Frequency | < 2.0 |
| Creatives | 15+ diverse active |

## Scaling Protocol

```
Day 1-3: Hold (validate stability)
Day 4: +15-20% (if metrics hold)
Day 5-6: Observe (no changes)
Day 7: +15-20% (if still stable)
Repeat until goal or issue
```

## Maximum Velocity

- **Aggressive:** 20% max per day
- **Safe:** 15% per day
- **Conservative:** 10% per day
- **NEVER:** >50% overnight

## Expert Sources
- Performance Expert: 72h rule, $500 minimum, 20% scaling limit
- Media Buying Expert: Funnel-specific thresholds, back-end focus
