# Audience Expansion Skill

## When to Use
- Campaign hitting ceiling
- Need to scale beyond current audience
- Frequency getting too high

## Andromeda Expansion Philosophy

```
OLD WAY (DEPRECATED):
- Create more audiences
- Stack lookalikes
- Detailed targeting expansion

NEW WAY (MANDATORY):
- Remove restrictions
- Broaden targeting
- Let algorithm find buyers
- Add MORE creatives, not audiences
```

## Expansion Hierarchy

### Priority 1: Creative Diversification (Default)
```
BEFORE expanding audience, always ask:
"Do we have 20+ diverse creatives?"

IF NO:
→ Add more creatives first
→ Different angles, formats, hooks
→ This is usually the actual solution

WHY:
Andromeda finds audience through creative
More creative diversity = more reach
```

### Priority 2: Remove Restrictions
```
CURRENT STATE → EXPANSION MOVE:

Interest targeting → Remove interests (go broad)
Age restriction 25-45 → Expand to 18-65+
Specific locations → Expand geography
Lookalike 1% → Remove lookalike (go broad)
Detailed expansion OFF → Turn ON (temporary)
```

### Priority 3: Budget Increase
```
AFTER creative diversity confirmed:

Week 1: +15-20%
Week 2: +15-20% if stable
Week 3: +15-20% if stable

ALGORITHM RESPONSE:
Higher budget = broader reach automatically
Don't need to "expand" audience manually
```

### Priority 4: New Placements
```
CURRENT → EXPANSION:

FB/IG only → Add Messenger, Audience Network
Feed only → Add Stories, Reels
Manual placements → Advantage+ Placements

NOTE: Advantage+ Placements usually optimal
```

### Priority 5: New Platforms (Last Resort)
```
SATURATED ON META:
→ Consider TikTok
→ Consider YouTube
→ Consider Google

THIS IS LAST RESORT because:
- Requires new creative formats
- Different optimization learning
- Split testing effort
```

## Expansion Checklist

```
BEFORE EXPANDING AUDIENCE:

□ Do we have 20+ active creatives?
  IF NO → Add creatives first

□ Are creatives diverse (5+ angles)?
  IF NO → Add new angles

□ Is frequency < 2.5?
  IF YES → Don't need to expand yet

□ Are metrics stable?
  IF NO → Fix metrics first

□ Have we tried removing restrictions?
  IF NO → Try broad first

□ Have we increased budget?
  IF NO → Try +20% budget first
```

## Anti-Patterns (What NOT to Do)

```
❌ Creating new lookalike audiences
   → Andromeda does this automatically

❌ Stacking interest targeting
   → Restricts algorithm reach

❌ Creating multiple similar ad sets
   → Causes auction overlap

❌ Expanding geo before creative
   → Creative is the scaling lever

❌ Splitting audience by device
   → Algorithm optimizes this
```
