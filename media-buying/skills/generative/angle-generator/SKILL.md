# Angle Generator Skill

## When to Use
- Need creative diversity for Andromeda
- Testing new messaging approaches
- Breaking creative monotony

## What is an Angle?

```
ANGLE = Psychological motivation being targeted

Different from:
- Hook = The attention-grabber (tactical)
- Copy = The full message (execution)
- Creative = The visual/video (format)

ANGLE is the WHY behind the message.
```

## The 15 Core Angles

### 1. Fear of Missing Out (FOMO)
```
TARGETS: Fear of being left behind
MESSAGE: "Everyone else is doing it, you're falling behind"
HOOKS: Urgency, scarcity, exclusivity
EXAMPLE: "While you hesitate, your competitors are scaling"
```

### 2. Pain Avoidance
```
TARGETS: Desire to escape suffering
MESSAGE: "Stop the pain you're experiencing"
HOOKS: Problem agitation, current frustration
EXAMPLE: "Stop losing money on ads that don't convert"
```

### 3. Pleasure Seeking
```
TARGETS: Desire for positive outcomes
MESSAGE: "Imagine how good it will feel"
HOOKS: Transformation, lifestyle
EXAMPLE: "Wake up to notifications of sales while you sleep"
```

### 4. Social Proof
```
TARGETS: Safety in numbers
MESSAGE: "Others like you have succeeded"
HOOKS: Testimonials, numbers, authority
EXAMPLE: "Join 10,000+ marketers who scaled to 7 figures"
```

### 5. Authority Trust
```
TARGETS: Trust in experts
MESSAGE: "The experts recommend this"
HOOKS: Credentials, endorsements, credentials
EXAMPLE: "The method taught at Harvard Business School"
```

### 6. Contrarian
```
TARGETS: Desire to be different
MESSAGE: "The common advice is wrong"
HOOKS: Industry disruption, myth-busting
EXAMPLE: "Forget everything you learned about targeting"
```

### 7. Curiosity
```
TARGETS: Information gap
MESSAGE: "There's something you don't know"
HOOKS: Secrets, hidden methods, discoveries
EXAMPLE: "The algorithm hack nobody talks about"
```

### 8. Identity
```
TARGETS: Self-perception
MESSAGE: "This is who you could be"
HOOKS: Transformation, belonging, status
EXAMPLE: "Become the marketer everyone asks for advice"
```

### 9. Simplicity
```
TARGETS: Desire for ease
MESSAGE: "It's easier than you think"
HOOKS: Step-by-step, done-for-you, shortcuts
EXAMPLE: "3 clicks to set up your entire campaign"
```

### 10. Speed
```
TARGETS: Impatience
MESSAGE: "Get results faster"
HOOKS: Quick wins, shortcuts, acceleration
EXAMPLE: "First results in 48 hours, not 48 days"
```

### 11. Value
```
TARGETS: Getting a deal
MESSAGE: "Worth more than you're paying"
HOOKS: Comparison, savings, ROI
EXAMPLE: "Get $10,000 worth of training for $997"
```

### 12. Safety/Risk Reversal
```
TARGETS: Fear of loss
MESSAGE: "You can't lose"
HOOKS: Guarantees, refunds, proof
EXAMPLE: "100% money back if no results in 90 days"
```

### 13. Belonging
```
TARGETS: Community desire
MESSAGE: "Join your tribe"
HOOKS: Community, insider access, exclusivity
EXAMPLE: "Join the inner circle of 7-figure marketers"
```

### 14. Achievement
```
TARGETS: Accomplishment drive
MESSAGE: "Reach your goal"
HOOKS: Milestones, levels, progression
EXAMPLE: "Finally hit $100K months consistently"
```

### 15. Logic/Data
```
TARGETS: Rational decision-makers
MESSAGE: "The numbers prove it"
HOOKS: Statistics, case studies, ROI
EXAMPLE: "87% of students ROI within 30 days"
```

## Angle Selection Matrix

```
AUDIENCE TEMPERATURE → BEST ANGLES:

COLD:
- Curiosity (open loops)
- Contrarian (pattern interrupt)
- Social Proof (build trust)

WARM:
- Identity (they want to belong)
- Achievement (they see the goal)
- Value (comparing options)

HOT:
- FOMO (urgency to act)
- Safety (remove final doubts)
- Speed (they want it now)
```
