## Generation Process

### Step 1: Understand Offer
```
GATHER:
- Product/service name
- Core benefit
- Target audience
- Price point
- Unique mechanism
```

### Step 2: Select Categories
```
FOR COLD AUDIENCES:
- Curiosity Gap (primary)
- Problem Agitation
- Industry Disruption

FOR WARM AUDIENCES:
- Transformation
- Social Proof
- Urgency

FOR RETARGETING:
- Urgency
- Social Proof
- Tactical
```

### Step 3: Generate Variations
```
PER CATEGORY:
- 3-5 hook variations
- Different lengths (short/medium/long)
- Different tones (casual/professional)
- Different formats (question/statement)
```
