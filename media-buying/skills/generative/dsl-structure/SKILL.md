# DSL Structure Skill

## When to Use
- Creating video ad scripts
- Structuring UGC content
- Building talking-head ads

## The DSL Framework

### D = DISRUPT (0-3 seconds)
```
PURPOSE: Stop the scroll
METHOD: Pattern interrupt

REQUIREMENTS:
- Must hook in first 3 seconds
- Visual + audio disrupt
- Unexpected element
- Question or bold statement

FORMATS:
- "Wait, what?"
- "Nobody told you this..."
- "Stop scrolling if..."
- "I need to tell you something..."
- Visual surprise
```

### S = STORY (3-45 seconds)
```
PURPOSE: Build connection and credibility
METHOD: Relatable narrative

STRUCTURE:
1. The "before" state (relatable pain)
2. The discovery/turning point
3. The transformation
4. The proof (results, testimonials)

REQUIREMENTS:
- Specific details (names, numbers, dates)
- Emotional connection
- Builds to the solution
- Maintains attention
```

### L = LANDING (45-60 seconds)
```
PURPOSE: Drive action
METHOD: Clear CTA with urgency

REQUIREMENTS:
- Tell them exactly what to do
- Add urgency element
- Remove friction
- Risk reversal if applicable

FORMATS:
- "Click the link below"
- "Comment [word] and I'll send you..."
- "Register now before..."
- "Limited spots available"
```

## Script Templates

### Template 1: Standard DSL (60 seconds)
```
[DISRUPT - 0:00-0:03]
"{Pattern interrupt hook}"

[STORY - 0:03-0:45]
"Let me tell you what happened...
[Before state - 10 sec]
[Discovery moment - 10 sec]
[Transformation - 15 sec]
[Proof/results - 10 sec]"

[LANDING - 0:45-1:00]
"Here's what I want you to do...
[CTA - 10 sec]
[Urgency - 5 sec]"
```

### Template 2: Quick DSL (30 seconds)
```
[DISRUPT - 0:00-0:03]
"{Hook}"

[STORY - 0:03-0:20]
"Quick story: [Before] → [Discovery] → [Result]"

[LANDING - 0:20-0:30]
"[CTA] + [Urgency]"
```

### Template 3: Extended DSL (90 seconds)
```
[DISRUPT - 0:00-0:05]
"{Double hook: visual + verbal}"

[STORY PART 1 - 0:05-0:30]
"[Deep dive into before state]
[Emotional connection]"

[STORY PART 2 - 0:30-0:60]
"[The discovery]
[The transformation process]
[Multiple proof points]"

[LANDING - 0:60-0:90]
"[Detailed CTA]
[Address objection]
[Urgency]
[Final hook]"
```
