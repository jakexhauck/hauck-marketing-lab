# Creative Brief Skill

## When to Use
- Briefing designers for static ads
- Briefing editors for video ads
- Documenting creative direction

## Brief Components

### 1. Project Overview
```
- Project name
- Client/offer
- Deadline
- Format(s) needed
- Quantity
```

### 2. Target Audience
```
- Demographics (age, gender, location)
- Psychographics (beliefs, fears, desires)
- Awareness level (cold/warm/hot)
- Pain points (specific)
- Desired outcome (specific)
```

### 3. Message Direction
```
- Hook (the attention-grabber)
- Core message (the takeaway)
- Proof elements (credibility)
- CTA (what to do next)
```

### 4. Visual Direction
```
- Style (modern, classic, bold, minimal)
- Color palette (specific hex codes or reference)
- Typography (font family/weight)
- Energy level (high/medium/calm)
- Reference images (links/attachments)
```

### 5. Technical Specs
```
- Format (static/video/carousel)
- Dimensions (1080x1080, 1080x1920, etc.)
- Duration (for video: 15s, 30s, 60s)
- File format (JPG, PNG, MP4)
- Platform (Meta, TikTok, YouTube)
```
