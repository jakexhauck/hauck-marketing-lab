# Copy Generator Skill

## When to Use
- Creating new ads
- Testing copy variations
- Refreshing existing ads

## Ad Copy Structure

### Primary Text (Body)
```
LENGTH OPTIONS:
- Short: 1-2 sentences (mobile-first)
- Medium: 3-4 sentences (standard)
- Long: 5+ sentences (story format)

STRUCTURE:
1. Hook (first line visible)
2. Problem/Promise
3. Solution/Proof
4. CTA

CHARACTER LIMITS:
- First 125 chars always visible
- Full text: 2,200 chars max
- Sweet spot: 150-250 chars
```

### Headlines
```
LENGTH: 25-40 characters ideal
PURPOSE: Reinforce hook, add clarity

FORMATS:
- Benefit statement
- Question
- How-to
- Number-based
- Challenge
```

### Descriptions
```
LENGTH: 20-30 characters
PURPOSE: Support headline, add urgency

FORMATS:
- Action phrase
- Benefit micro-copy
- Social proof snippet
- Urgency element
```

## Copy Formulas

### PAS (Problem-Agitate-Solve)
```
[Problem] → [Agitate] → [Solution]

Example:
"Struggling to get clients? (P)
Every day without leads costs you thousands. (A)
This 3-step system changes everything. (S)"
```

### AIDA (Attention-Interest-Desire-Action)
```
[Attention hook]
[Interest builder]
[Desire amplifier]
[Action CTA]
```

### BAB (Before-After-Bridge)
```
[Before state]
[After state]
[Bridge = your offer]
```

### DSL (Disrupt-Story-Landing)
```
[Disrupt with hook]
[Story/proof]
[Land with CTA]
```
